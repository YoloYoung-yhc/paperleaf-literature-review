# Paperleaf · 文献综述生成器

输入研究主题，自动检索相关文献、整理研究脉络，生成中文或英文综述初稿，并下载可编辑的 Word 文档。

**输入主题 → 检索文献 → 生成综述 → 查看引用 → 下载 Word**

## 开始使用

打开网站即可使用。如果你下载的是 [`Paperleaf-Literature-Review.html`](Paperleaf-Literature-Review.html) 文件，用支持 JavaScript 的现代浏览器打开即可，无需安装其他软件。

使用前请准备：

- 可以访问网络的浏览器。
- 你自己的模型 API Key，以及对应的接口地址和模型名称。

手机建议在系统浏览器中打开网站。聊天软件内的 HTML 文件预览器可能无法运行完整功能。

## 第一步：配置 API

点击页面右上角的「配置你的 API」，填写以下信息：

| 项目 | 如何填写 | 示例 |
| --- | --- | --- |
| Base URL | 模型服务商提供的兼容接口地址 | `https://api.deepseek.com/v1` |
| API Key | 你在该服务商账户中申请的密钥 | 填写自己的 Key |
| 模型名称 | 服务商提供、且你的账户可以使用的模型 ID | `deepseek-chat` |

以上仅为配置示例，请以你使用的服务商当前提供的信息为准。地址、Key 和模型名称应属于同一套服务。接口需要兼容 **Chat Completions**。

填写后点击「测试模型连接」。出现连接成功提示后，就可以开始生成。连接测试只确认模型接口可以响应，不代表所有长文本任务都一定能完成。

**费用说明：**每位使用者使用自己的模型账户，一篇综述会产生多次模型调用，具体费用和额度由对应服务商计算。

### 可选：添加玻尔检索

如果你有独立的 Bohrium Access Key，可以填写「玻尔检索 Access Key（可选）」，额外检索玻尔文献。不填写也能使用其他文献来源。

玻尔 Key 与模型 API Key 不同，不能互换。可在玻尔「用户设置 → 账号」查找 Access Key，具体位置和权限以平台当前界面为准。玻尔论文接口按次收费，费用由你的玻尔账户承担。「测试模型连接」不会测试玻尔权限。

## 第二步：输入研究主题

在「你想研究什么？」中输入研究领域、作业题目或研究问题。不必自行整理详细英文关键词，系统会自动扩展相关学术术语和同义词。

例如：

- 通用力场与机器学习势的发展及其在物理模拟中的应用
- 生成式人工智能在高等教育中的应用与挑战
- 社交媒体使用与大学生心理健康

选择中文或英文后，可以直接生成，也可以展开「更多要求」进一步设置：

| 设置 | 说明 |
| --- | --- |
| 目标篇幅 | 默认约 3000 字或词，可设置 1000–6000；中文按字数、英文按词数 |
| 文献数量 | 默认 15 篇，可设置 5–25 篇；实际数量取决于相关性和可用证据 |
| 年份范围 | 默认从当前年份前 5 年至当前年，包含首尾年份，可自行调整 |
| 老师的要求 | 可填写作业重点、需要比较的方法、讨论角度等，最多 2000 字符 |

目标篇幅是写作目标，不是精确字数承诺。设置年份范围后，自动扩展关键词不会改变你选择的年份。

## 第三步：生成并核对综述

点击「生成文献综述」，页面会显示当前进度。系统会自动检索、筛选文献，整理证据并撰写正文。

**生成过程中请保持页面打开。**尤其是直接使用 HTML 文件时，刷新、关闭页面、手机锁屏或长时间切到后台，都可能中断任务。

完成后，可以查看两个部分：

- **综述初稿**：阅读正文，点击引用编号查看对应文献。
- **文献与证据**：查看题录、原始摘要、来源链接和引用证据片段，核对正文是否得到文献支持。

检索词、实际采用的文献数量、来源问题和证据覆盖情况，可以在「检索与生成说明」中查看。文献不足时会说明，不会为了凑数量补写参考文献。

## 第四步：下载 Word

点击「下载 Word」，保存 `.docx` 文件后即可继续编辑。

文档包含标题、摘要、关键词、正文、参考文献及检索说明。当前摘要摘取自已核对的首个正文部分首段，页面和文档中会标明。

建议下载后完成以下检查：

1. 确认内容符合题目和老师的要求。
2. 打开重要引用的原文，核对关键论断、数值与研究结论。
3. 根据需要调整表达、篇幅和格式，加入自己的分析。

## 文献从哪里来

| 来源 | 主要提供的内容 |
| --- | --- |
| OpenAlex | 跨学科文献题录与摘要 |
| Crossref | 出版方提供的文献信息与摘要 |
| arXiv | 预印本题录与摘要，明确标记预印本来源 |
| Semantic Scholar | 跨学科文献信息与摘要补充 |
| PubMed / Europe PMC | 生物医学文献，以及部分 PMC 开放全文节选 |
| Bohrium（玻尔） | 填写独立 Access Key 后额外检索的文献 |

不同来源会合并去重，再根据题目筛选。可获取的题录、摘要和全文范围不同；有来源链接不代表已经阅读全文。arXiv 来源也不能据此认定已经通过同行评审。

部分来源可能受到网络、跨域权限或额度限制。某个来源暂时不可用时，其他来源仍会继续尝试。多来源检索可以扩大覆盖，但不能保证找到全部相关文献。

## 常见问题

| 问题 | 如何处理 |
| --- | --- |
| HTML 能打开，但不能检索或生成 | 页面可以离线打开，检索和 AI 写作仍需要联网；同时检查 API 配置 |
| 提示 API 认证失败 | 检查接口地址、Key 和模型名称是否匹配，以及账户权限和余额 |
| 提示网络或跨域（CORS）错误 | 检查网络；直接使用 HTML 时，模型服务商必须允许浏览器调用，可换用支持的接口 |
| 测试连接成功，生成仍失败 | 查看具体失败步骤；连接测试是小请求，实际生成还受模型输出能力、额度和速率限制 |
| 模型输出被截断 | 系统会尝试分段处理；若仍失败，可稍后重试或换用支持更长输出的模型 |
| 找到的文献较少 | 系统会自动扩展关键词；仍不足时可调整年份范围，或把研究主题说明得更清楚 |
| 玻尔没有检索结果 | 检查独立 Access Key、接口权限、余额和网络情况；模型连接测试不验证玻尔 |
| 刷新后显示任务中断 | 浏览器中的生成已停止，需要重新生成；重新生成可能再次产生调用费用 |
| Word 无法下载 | 确认任务已经完成，再尝试下载；任务过期或会话丢失后需要重新生成 |
| 手机上只有文件预览，无法操作 | 改用系统浏览器打开网站，不要只在聊天软件或文件预览器中查看 |

## 隐私与结果保存

- API 配置和任务访问凭证在浏览器允许的情况下保存在当前标签页的会话中，可点击「清除 Key」清除模型和玻尔凭证。
- 直接使用 HTML 文件时，请求由浏览器发送给你选择的模型和文献服务，不经过网站后台。部分浏览器不允许本地文件保存会话数据。
- 题目、作业要求和文献证据会按流程发送给相关服务，不要在输入内容中填写敏感信息。
- 已完成结果在同一会话中可恢复查看，最长 24 小时；关闭会话或清空浏览器数据后可能无法恢复，请及时下载 Word。
- 请勿公开分享自己的 API Key，也不要把它写进分享给他人的 HTML 文件。

## 使用须知

Paperleaf 提供的是辅助阅读和写作的**叙述性综述初稿**，不替代系统综述、专业检索或对原文的阅读。真实文献来源和自动核对不能保证每项论断都正确，提交前请自行核查，并遵循课程、学校或期刊对 AI 使用的要求。
